# textbook-study-hub

StudySphere is a modern study website for discovering and organizing maths and physics resources, including textbooks, reference guides, and recommended learning paths.

## Included resources

- Mathematics topics: algebra, trigonometry, calculus, linear algebra, probability, statistics, geometry, differential equations, discrete mathematics, and number theory
- Physics topics: mechanics, electricity and magnetism, waves and optics, thermodynamics, modern physics, quantum physics, fluid mechanics, and solid mechanics
- Search and filter tools to browse the resource library quickly
- Responsive design for desktop and mobile devices

## Run locally

Open `index.html` in your browser, or serve the project with any static file server.

Example:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Files

- `index.html` — page structure
- `styles.css` — styling and responsive layout
- `script.js` — resource data, filtering, and search logic
